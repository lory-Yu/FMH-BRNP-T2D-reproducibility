# Manuscript availability text

Status: verified for manuscript use. The public GitHub repository and the
Zenodo archive for release `v1.1.0-bmc-microbiology` are available.

## Code availability

The analysis code, reproducible workflows, environment specifications, and
instructions required to reproduce the publicly redistributable components of
this study are available at
https://github.com/lory-Yu/FMH-BRNP-T2D-reproducibility. The BMC Microbiology
release `v1.1.0-bmc-microbiology` is archived at Zenodo
(https://doi.org/10.5281/zenodo.23097072).

## Data availability

Study-generated derived outputs, accession manifests, source-data tables for
reproducible figures, input schemas, checksums, and reconstruction instructions
are provided in the accompanying repository.
Certain row-level integrated inputs derived from third-party databases are not
redistributed because their source terms do not clearly establish
redistribution permission. The relevant source databases, provenance, schemas,
and reconstruction procedures are documented to enable researchers with
appropriate access to reconstruct these inputs locally.

The redistributable BMC Microbiology analyses and Figures 1–4 can be regenerated
from the released materials and the documented external inputs. Complete
from-scratch execution of workflows that use non-redistributed third-party
database-derived transformation inputs requires local reconstruction under the
source providers' terms.
