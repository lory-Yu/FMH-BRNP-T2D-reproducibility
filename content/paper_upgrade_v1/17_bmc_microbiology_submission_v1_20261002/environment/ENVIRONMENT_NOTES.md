# Environment and external-input notes

- Python analyses were run with Python 3.13 and the versions recorded in the
  parent reproducibility documentation.
- The F1 model screen used COBRApy 0.31.1, optlang GLPK and the frozen
  tolerance documented in the manuscript.
- The Wei 16S workflow used DADA2 1.38.0 and SILVA 138.2.
- AGORA2 SBML files, SILVA training sets and restricted third-party tables are
  intentionally not redistributed. Users must obtain them from their
  authoritative sources and provide local paths to the portable scripts.
- No author workstation paths, credentials, tokens or private repository URLs
  are part of this release.
